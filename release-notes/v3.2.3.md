Start with Windows now keeps working when Scoop updates the app.

**Already on 3.0 or later?** The app offers this update by itself within a day, or now from **Settings → Updates → Check for updates**. Installed with Scoop: `scoop update unifistockwatcher`.

**New here?** Download [`UnifiStockWatcher-Setup.exe`](https://github.com/jamesccupps/UnifiStockWatcher/releases/download/v3.2.3/UnifiStockWatcher-Setup.exe) (installs for your Windows user, no admin prompt) or the portable [`UnifiStockWatcher-win64.zip`](https://github.com/jamesccupps/UnifiStockWatcher/releases/download/v3.2.3/UnifiStockWatcher-win64.zip), or install it with [Scoop](https://scoop.sh):

```
scoop bucket add jamesccupps https://github.com/jamesccupps/scoop-bucket
scoop install jamesccupps/unifistockwatcher
```

The app isn't code-signed, so Windows may say *Windows protected your PC*: **More info → Run anyway**.

### Fixed

- **Start with Windows on a Scoop install.** It started the exact version you turned it on in, so after `scoop update` signing in still started the old version (and starting the new one just brought the old one up), and after `scoop cleanup` nothing started at all. It now starts whichever version Scoop has current. If you turned it on in an earlier version, it's moved over the first time 3.2.3 starts; nothing to do. The installer and the portable zip weren't affected.

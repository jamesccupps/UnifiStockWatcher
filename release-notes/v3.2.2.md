One copy at a time, the command-line watcher included.

**Already on 3.0 or later?** The app offers this update by itself within a day, or now from **Settings → Updates → Check for updates**.

**New here?** Download [`UnifiStockWatcher-Setup.exe`](https://github.com/jamesccupps/UnifiStockWatcher/releases/download/v3.2.2/UnifiStockWatcher-Setup.exe) (installs for your Windows user, no admin prompt) or the portable [`UnifiStockWatcher-win64.zip`](https://github.com/jamesccupps/UnifiStockWatcher/releases/download/v3.2.2/UnifiStockWatcher-win64.zip). The app isn't code-signed, so Windows may say *Windows protected your PC*: **More info → Run anyway**.

### Fixed

- **The app and the command-line watcher no longer run together.** Running both alerted twice for every product, and an update could replace the program's files while the watcher was still using them. Now whichever starts second says the other is running and exits. (The watcher's `--test` and `--version` still run any time.)
- **Starting the app twice quickly opens one copy.** If you started it again while it was still loading (two clicks on the shortcut, say, or Start with Windows and a click), a second copy started beside it. Now the second one waits for the first and brings its window up.

Releases are now signed in a separate step of the release build, so the signing key is never on the machine that builds the program.
